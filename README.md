# Student Management System

A simple console-based Student Management System built in Python. This project was built to practice core Python fundamentals — variables, loops, functions, dictionaries, and object-oriented programming (OOP).

## Features

- **Add a student** — store name, roll number, and marks for 5 subjects (Maths, Science, English, French, Social Studies)
- **View all students** — displays all student records in a table format
- **Search a student** — look up a student by roll number
- **Update student details** — update a student's name or their marks in a specific subject
- **Delete a student** — remove a student record by roll number

## Concepts Practiced

- Object-Oriented Programming (classes, objects, __init__, attributes)
- Loops and conditionals
- Dictionaries (storing and updating subject-wise marks)
- Functions and parameters
- f-strings and string formatting (column alignment)
- Basic input validation and the "found flag" search pattern

## How to Run

1. Make sure Python is installed on your system
2. Clone this repository or download proj1.py
3. Run the file: python proj1.py
4. Follow the on-screen menu to add, view, search, update, or delete students

## Menu Options

1. Add a new Student
2. View all student details
3. Search for student
4. Update student details
5. Delete a student
6. Exit
